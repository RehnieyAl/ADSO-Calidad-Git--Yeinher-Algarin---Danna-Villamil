# Proyecto Calculadora - ADSO Calidad SQA

## Descripción del Proyecto
Este proyecto es una calculadora desarrollada en Python, construida aplicando estándares de aseguramiento de la calidad (SQA) mediante el uso de Git y GitHub.

## Módulos Desarrollados
- **Módulo de División:** Desarrollado por Yeinher Algarin.
- **Módulo de Suma:** Desarrollado por Danna Villamil. Permite sumar dos números validando que los datos ingresados sean correctos.
